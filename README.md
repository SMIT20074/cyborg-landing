# Seam: Cyborg-Themed Landing Page

Responsive landing page for the Techfest CA Program web development task.

**Concept:** The hero is split by a draggable seam. The left side is human (warm paper, serif type); the right side is machine (steel, grid, neon cyan). Drag the seam, or use the arrow keys on the handle, to move between them.

## Features
- Draggable before/after hero with keyboard support
- Count-up stats, interactive booking button
- Fully responsive, respects `prefers-reduced-motion`
- Single file, no build step: HTML, CSS and vanilla JS

## Run
Open `index.html` in a browser.
